## 📖 Sobre

Site simples e leve para uma profissional da área de estética, servindo como cartão de visita online: uma página inicial com apresentação e páginas dedicadas aos serviços de **cílios** e **sobrancelhas**, além de links para contato (WhatsApp e Instagram). Projeto focado em praticar **HTML e CSS** e estruturação de páginas.

## ✨ Funcionalidades

- 🏠 Página inicial com apresentação da profissional
- 👁️ Páginas dedicadas aos serviços (cílios e sobrancelhas)
- 📱 Links diretos para **WhatsApp** e **Instagram**
- 🎨 Layout construído do zero com HTML e CSS

## 🛠️ Tecnologias

- **HTML5**
- **CSS3**

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/Erikjuniorsilva/Blog-Pamella.git
cd Blog-Pamella
```

Abra o arquivo `index.html` no navegador (ou use a extensão *Live Server*).
